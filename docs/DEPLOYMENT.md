# GitHub Pages

The site is already static. Publishing does not need a build.

1. Use a repository whose root contains this `index.html`.
2. Keep `Input/` out of Git. `.gitignore` lists `input/` and `Input/`.
3. In GitHub, open **Settings → Pages**.
4. Set **Build and deployment** to **Deploy from a branch**.
5. Choose the branch and the folder **`/ (root)`**.
6. Save, and wait for the Pages deployment to finish.

Do not enable Pages until the design and the submission figures have been approved.
